## getContextTabGroupId()
- 位置: L22-23
- 役割: ポップアップの triggerNode から最寄りの data-tab-group-id を持つ要素を辿り、そのタブグループ ID を返す。
- 触るとき: タブグループの右クリックメニュー項目が対象グループを取り違えるとき、または triggerNode が子要素(ラベルやアイコン)のときの対象解決を変えるとき。
- 呼び出し先: `popup.triggerNode?.closest()`
- 参照: `popup.triggerNode?.closest("[data-tab-group-id]")?.dataset.tabGroupId`

## dismissTabGroupPanel()
- 位置: L25-28
- 役割: triggerNode の最寄りのパネルを探し、keepopenongroupdelete 属性を持たないものだけ hidePopup で閉じる。
- 触るとき: タブグループの削除後にパネルを閉じる範囲を変えるとき、またはパネルを閉じたくないパネルに keepopenongroupdelete を付けるとき。
- 呼び出し先: `popup.triggerNode ?.closest()`, `popup.triggerNode ?.closest("panel:not([keepopenongroupdelete])") ?.hidePopup()`
